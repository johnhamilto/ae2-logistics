# Pattern Import Card

<ItemImage id="pattern_import_card" scale="2" />

**Encoding never runs dry.** Keep the card anywhere in your inventory: while a
Pattern Encoding Terminal window is open, its blank-pattern slot restocks
itself from network storage. No more ferrying stacks of blanks to the terminal.

- Restocks in batches of eight whenever the slot runs empty; blanks come from
  the same storage the terminal shows, so security and view rules apply.
- Works with every host that opens AE2's encoding window: the cable part, the
  wireless forms, and ExtendedAE's extended terminal.
- The card never consumes itself; craft one and forget it.
