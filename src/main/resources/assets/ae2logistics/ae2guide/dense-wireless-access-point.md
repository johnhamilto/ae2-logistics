# Dense Wireless Access Point

<BlockImage id="dense_wireless_access_point" scale="4" />

The carrier tier for [wireless machine bridging](wireless.md): a wireless access
point with extended range, built to serve
[ME Wireless Bridges](wireless-bridge.md).

- Default range 32 blocks (server-configurable), against AE2's base 16.
- AE2's own Wireless Access Points also serve bridges - the dense WAP just does
  it at range and is the natural backbone antenna.
