# AE2 Logistics

AE2 gives you a storage plane (what you have) and an execution plane (what you craft).
AE2 Logistics adds the missing **control plane**: numbers your network can carry, logic
that computes with them, and patterns that match ingredients flexibly.

The systems, one page each:

- **Signals** — named numeric channels that live on your network, show up in terminals,
  and drive Level Emitters; the Register Bank and Tracer Terminal live here.
- **Logic Parts** — cable parts that read and write signals: thresholds, hysteresis,
  arithmetic, timers, sensors — plus the ME Job Monitor.
- **Adaptive Patterns** — processing patterns that accept "any #planks" or "any damage"
  instead of one exact item, made at the Pattern Workbench.
- **Guarded Crafting** — providers and patterns gated behind signal conditions, priced
  by the Regulus Crystal.
- **ME Job Scheduler** — stock keeping with admission control, class pools, deadlines,
  and preemption.
- **ME Logic Core** — eight virtual logic nodes as list entries in one block.
- **Wireless Bridging** — machines join the network through access point coverage.
- **ME Subnet Core** — an entire subnet as configuration inside one block.
- **P2P Frequency Terminal** — named frequencies, one-table linking, mesh rows.
- **Query Language** — saved, named expressions over storage; terminal, sensor, and
  export bus.
- **ME Config Terminal** — audit and edit every device, snapshot diffs, and the
  Config Blueprint.
- **Universal Mesh Endpoints** — six transports over named many-to-many frequencies.

Everything is server-computed, deterministic, and designed to sleep when idle.
