# Pattern Import Card

<ItemImage id="pattern_import_card" scale="2" />

**Encoding never runs dry.** Installed in a wireless encoding terminal's upgrade
slots, the card restocks the terminal's blank-pattern slot from network storage
while its window is open. A card in your pocket does nothing - it works from
upgrade slots, like every other card.

- Fits AE2WTLib's **Wireless Pattern Encoding Terminal** and **Universal
  Terminal**, next to their other upgrade cards.
- Restocks in batches of eight whenever the slot runs empty; blanks come from
  the same storage the terminal shows, so security and view rules apply.
- The cable-mounted encoding terminal has no upgrade slots, so the card does not
  work there.
