# Pattern Import Card

<ItemImage id="pattern_import_card" scale="2" />

**Encoding never runs dry.** Installed in a Pattern Encoding Terminal, the card
restocks the terminal's blank-pattern slot from network storage while its window
is open. Installed per terminal - a card in your pocket does nothing.

- **Cable-part terminal**: sneak-click the terminal with the card to build it in
  (the card is consumed); sneak-click with an empty hand to pop it back out. The
  install rides the cable side under the part.
- **Wireless terminals** (AE2WTLib): the card goes into the terminal's normal
  upgrade slots, next to its other cards. Works in the dedicated Wireless
  Pattern Encoding Terminal and the Universal Terminal.
- Restocks in batches of eight whenever the slot runs empty; blanks come from
  the same storage the terminal shows, so security and view rules apply.
